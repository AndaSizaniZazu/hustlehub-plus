01

What is a function, really?

Think of a function like a recipe card. The card sits in a drawer doing nothing until you decide to use it. When you do, you can hand it ingredients, it does some steps, and it might hand something back.

function greet(personName) {
  return "Hello, " + personName + "!";
}

That block on its own does nothing yet — it just defines the recipe. Nothing happens until you call it by name:

const message = greet("Alex");
console.log(message);

Let's actually run both lines together, for real, so you see the recipe get used:

$ node -e 'function greet(personName){return "Hello, "+personName+"!";} console.log(greet("Alex"));'
Hello, Alex!
The one sentence to remember: writing a function just defines the recipe. Calling it — writing its name followed by () — is what actually runs the steps.
02

Two ways to write the same function

JavaScript lets you write a function two different ways. They do the same job — you'll see both in real code, so it's worth recognizing both shapes.

The function keyword

function greet(personName) {
  return "Hello, " + personName;
}

Arrow function

const greet = (personName) => {
  return "Hello, " + personName;
};

Read the arrow version out loud as: "greet is a value — specifically, a function — that takes personName and produces (=>) whatever's in the { }." Modern JavaScript code (including this whole project) reaches for the arrow form almost every time.

03

Inputs and outputs: parameters & return

Two separate ideas that are easy to blur together at first:

  • Parameters — the named placeholders in the function's own definition, e.g. personName above. They're empty boxes waiting to be filled.
  • Arguments — the actual values you hand over when you call the function, e.g. "Alex" in greet("Alex"). The argument fills the parameter's box for that one run.
  • return — the value the function hands back to whoever called it. A function with no return silently hands back undefined — "nothing."

A function can take more than one input, in order:

function addTax(price, taxRate) {
  return price + (price * taxRate);
}
$ node -e 'function addTax(price,taxRate){return price+(price*taxRate);} console.log(addTax(100, 0.15));'

04

Functions can be passed around like any other value

This is the idea that unlocks everything later (including how the actual server code works), so sit with it slowly: a function isn't just something you call — it's a value, exactly like a string or a number is a value. That means you can hand a function into another function as an input.

function runTwice(someFunction) {
  someFunction();
  someFunction();
}

function sayHi() {
  console.log("hi!");
}

runTwice(sayHi);
$ node -e 'function runTwice(fn){fn();fn();} function sayHi(){console.log("hi!");} runTwice(sayHi);'
hi!
hi!

Notice sayHi is passed without the parentheses — sayHi means "the recipe itself"; sayHi() would mean "run it right now." runTwice is the one deciding when to actually call it (twice, in this case).

Why this matters for later: every route handler in this project — app.get('/api/health', (req, res) => {...}) — is exactly this pattern. You're not calling that arrow function yourself; you're handing it to Express, and Express calls it later, whenever a matching request actually arrives.
05

So what is a "method"?

A method is just a function that already belongs to a value, called with a dot instead of standing on its own:

Plain function

greet("Alex")

Method (dot syntax)

"  Alex  ".trim()

.trim() is a function that every string already comes with, built into the language — you're not defining it, JavaScript already did. The rest of this guide is a tour of the most useful ones that come built-in on strings, arrays, objects, and numbers.

06

String methods

text values
.trim()

Removes whitespace from both ends.

"  Alex  ".trim()
"Alex"
.toLowerCase()

Converts every letter to lowercase.

"HELLO".toLowerCase()
"hello"
.toUpperCase()

Converts every letter to uppercase.

"hello".toUpperCase()
"HELLO"
.includes()

True/false — does the string contain this?

"hi@example.com".includes("@")
true
.slice(start, end)

Cuts out a piece of the string by position.

"hello world".slice(0, 5)
"hello"
.split(separator)

Breaks a string into an array of pieces.

"a,b,c".split(",")
["a", "b", "c"]
.replace(old, new)

Swaps the first match for something else.

"hello".replace("h", "j")
"jello"
.startsWith()

True/false — does it begin with this?

"hello".startsWith("he")
true
Where this shows up in the project: body('name').trim().notEmpty().withMessage(...) in auth.routes.js chains several string-related methods in a row — each one runs on the result of the last.
07

Array methods

lists of values

An array is an ordered list, written with square brackets: ["client", "freelancer"].

.length

Not a method — a property. How many items are in the list.

["client","freelancer"].length
2
.push(item)

Adds an item to the end, changing the original array.

arr.push("admin")
["client","freelancer","admin"]
.includes()

True/false — is this value in the list?

arr.includes("admin")
true
.indexOf()

Position of a value in the list (0 = first).

arr.indexOf("freelancer")
1
.join(separator)

Glues every item into one string.

arr.join(" | ")
"client | freelancer | admin"
.map(fn)

Builds a new array by transforming every item.

[1,2,3].map(n => n * 2)
[2, 4, 6]
.filter(fn)

Builds a new array keeping only items where fn is true.

[1,2,3,4].filter(n => n % 2 === 0)
[2, 4]
.find(fn)

Returns the first item where fn is true.

[1,2,3].find(n => n > 1)
2
.some(fn)

True if at least one item passes.

[1,2,3].some(n => n > 2)
true
.every(fn)

True only if all items pass.

[1,2,3].every(n => n > 0)
true
Notice: .map(), .filter(), .find(), .some(), and .every() all take a function as their input — this is Lesson 04 (functions as values) in action, just with a built-in method doing the calling instead of your own code.
08

Object methods

labeled bundles

Given const user = { name: "Alex", role: "client" }:

Object.keys(obj)

All the labels, as an array.

Object.keys(user)
["name", "role"]
Object.values(obj)

All the stored values, as an array.

Object.values(user)
["Alex", "client"]
Object.entries(obj)

Every [label, value] pair, as an array of pairs.

Object.entries(user)
[["name","Alex"], ["role","client"]]
09

JSON methods

talking to an API

These two are how a JavaScript object becomes the text an API sends over the network, and back again:

JSON.stringify(obj)

Object → text. This is what res.json() does for you automatically.

JSON.stringify(user)
'{"name":"Alex","role":"client"}'
JSON.parse(text)

Text → object. The reverse direction.

JSON.parse('{"name":"Alex"}')
{ name: "Alex" }

Number methods

math & conversion
.toFixed(2)

Rounds to a fixed number of decimal places.

(3.14159).toFixed(2)
"3.14"
parseInt(text)

Pulls a whole number out of the start of a string.

parseInt("42px")
42
parseFloat(text)

Same idea, but keeps decimals.

parseFloat("3.14 meters")
3.14
Number.isInteger()

True/false — is this a whole number?

Number.isInteger(5)
true
